# RRFlow change journals

**Status:** active generated change-journal index
**Coordinate:** `rrflow://rrflow-instance/data/evidence-index/change-journals`
**Owner:** discovery of immutable repository package receipts; linked from `docs/evidence/README.md`

Each completed repository package has one linked journal record. The records
report evidence and limitations; they do not own roadmap completion, POA&M
status, product maturity, or runtime lifecycle state.

The listing below is generated from the coordinated group indexes. Add or edit
a record in its owning group, then run
`python3 scripts/knowledge/render_navigation.py`.
