# D-11 estate-controller installed-instance binding journal

**Status:** active immutable change-journal evidence
**Coordinate:** `rrflow://rrflow-instance/data/evidence/change-journal/gate-d/d-11-estate-controller-installed-instance-binding-journal`
**Owner:** D-11 recoverability package receipt; the roadmap retains completion authority

This record reports one bounded D-11 package under POAM-006: the estate
controller's backup, prune, and restore paths resolve a managed instance as an
installed project through its locator and the estate's distribution binding,
open it as `serve` does, and act on the instance's own backup catalogue and
restore staging roots. The pre-canonical `<state-root>/backups|restores` lane
and the zero-token-key component open are removed. D-11 stays unchecked and
POAM-006 stays Open; the [Gate D owner](../../../roadmap/rrflow-1.0/gate-d.md)
retains acceptance.
