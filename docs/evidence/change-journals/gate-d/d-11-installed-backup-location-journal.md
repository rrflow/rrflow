# D-11 installed backup location journal

**Status:** active immutable change-journal evidence
**Coordinate:** `rrflow://rrflow-instance/data/evidence/change-journal/gate-d/d-11-installed-backup-location-journal`

This record reports one bounded D-11 prerequisite: backups and restore staging
of an installed estate now live inside the managed persistent container beside
the storage roots, where install recovery accepts them, instead of below
`roots/`, where it rejects them. It adds no command, no publication, and no
new operation. D-11 stays unchecked; the
[Gate D owner](../../../roadmap/rrflow-1.0/gate-d.md) retains acceptance.
