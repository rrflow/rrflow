# D-11 installed control state in backups journal

**Status:** active immutable change-journal evidence
**Coordinate:** `rrflow://rrflow-instance/data/evidence/change-journal/gate-d/d-11-installed-control-state-in-backups-journal`
**Owner:** D-11 recoverability package receipt; the roadmap retains completion authority

This record reports one bounded D-11 package: the first half of the POAM-031
remediation. An application-complete backup of an installed estate now carries
the estate's control state as a replayable control-journal archive, a restore
replays it in order and resumably, and a restored root holds the installed
record, install checkpoint, active configuration, security policy, audit chain,
and attunement state. Restore publication, which opens the restored root
through `open_installed`, is the next package. D-11 stays unchecked; the
[Gate D owner](../../../roadmap/rrflow-1.0/gate-d.md) retains acceptance.
