# C-07c installed 100-cycle reopen baseline

**Status:** active characterization baseline; implementation pending
**Coordinate:** `rrflow://rrflow-instance/data/evidence/change-journal/gate-c/c-07c-installed-reopen-baseline`
**Owner:** OBJ-02 prerequisite, [C-07c](../../../roadmap/rrflow-1.0/gate-c-07.md)

Public main is `cae8f3d9e3e0f733720a2f60ff5a8a3ab3094bf3`, tree
`50c979b1bd13c72a0610d49a7db12cc11914dd70`. The worktree was clean and
fetching development main confirmed the same revision. The preimplementation
brief in `target/c07c-reopen-pr.md` binds this package. GitHub requires a branch
commit before accepting the draft PR; this baseline supplies that seed only.

Ordinary installed history currently repeats three times. The component's
100-cycle histories do not qualify installed authorization, semantic state or
public transaction receipts. Add fixed fresh/existing 100-cycle histories
against the ordinary primary with independent requested rows, stable exact
retries, owned process termination and complete attempt reconciliation.
Dedicated native candidate jobs must explicitly run both long cases; ignored
default-suite cases cannot count as acceptance. Existing process/request
deadlines stay unchanged. Native correctness is distinct from constrained
capacity and 24-hour qualification.

Inspection also found that native `flush`, `compact` and `garbage_collect`
stop at the storage API. No installed engine maintenance operation invokes
them. Completing installed publication/reclamation must therefore establish
its governed engine path, not use a raw-store diagnostic shortcut. This is
within the existing C-07/POAM-035 missing installed-composition requirement.

No runtime changes or gate status changes are made by this baseline. Exact
commands, failures, implementation review and candidate evidence belong in
the successor implementation journal. The PR brief owns scope, oracle,
research/trace decisions, acceptance commands and stop conditions.
