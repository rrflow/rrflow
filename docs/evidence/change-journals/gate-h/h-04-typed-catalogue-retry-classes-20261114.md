**Changed behavior:**
- **Typed catalogue rows.** Each of the 83 operations is declared once through `operations!`. A row emits the `EndpointDescriptor` and a marker in `rrd_contract::operations` that implements `Operation` with the real request and response types, method, path, authentication, mutation flag and retry class. A wrong type name no longer compiles. The first build caught three markers that shared a name with their own response type (`QueryExport`, `TransactionPreview`, `AttunementReplanPreview`).
- **Retry classes.** `EndpointDescriptor` gains `retry`:
  - `read`: 42 operations;
  - `keyed_mutation`: 35;
  - `single_attempt`: 6.

  `EndpointCatalogue::validate` rejects a read class on a mutation and the reverse. OpenAPI carries `x-rrd-retry` per operation.
- **No client behavior changes yet.** The Rust client still uses its existing paths. Using the markers and retry classes is the design's next step.

**Evidence for the retry classes.** A read-only survey traced all 41 mutations to engine code and tests:
- **30 replay** the stored result under the idempotency key, for example `session.rs:140-150`, `transaction.rs:258-271` and `query.rs:312-325`.
- **5 are idempotent by their own semantics:** endpoint-configuration-apply, embedding-builtin-activate, task-budget-configure, task-budget-stop and task-close.
- **6 are `single_attempt`:**
  - `task-budget-resume` returns a conflict that hides the first outcome (`reasoning_budget/resume.rs:59-61`);
  - `task-embedding-execute`, `task-assessment-execute`, `task-endpoint-propose` and `task-worker-execute` reject a repeated attempt (`reasoning_budget/reserve.rs:68-80`);
  - `observation-deliver` re-sends to the external sink unless the delivery was acknowledged (`observation_delivery.rs:327-400`).

Three of these claims were re-read by hand: session replay, the budget-resume conflict, and the observation re-send.

**Survey findings recorded, not fixed here:**
- No test asserts that a catalogue row's `mutation` flag matches the server's `RrdOperation::mutates()`.
- Nine mutations require an idempotency key but key their replay on a payload identity instead.
- Replay is session-scoped for transactions, backup, restore, flight, task-open and knowledge.

**OpenAPI review.** The document changed only by `x-rrd-retry` on each operation and the `retry` field of the catalogue schema. `OPENAPI_DOCUMENT_SHA256` moves from `5c8f066a…` to `0e688c6b…`. The TypeScript, Python, Go, Java and .NET projections were regenerated by their own generators, and the five SDK references and the public-contract reference cite the new digest.
