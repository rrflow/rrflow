# H-06c named task records journal

**Status:** active immutable change-journal evidence
**Coordinate:** `rrflow://rrflow-instance/data/evidence/change-journal/gate-h/h06c-named-task-records`
**Owner:** H-06c named task records package receipt; not runtime or roadmap authority

This record reports one bounded package that adds named tasks: durable
records of one unit of intended work that prompt flights join, so rrflowQL
walks a task to its flights and each flight to the records its context used.
It follows the
[H-06b per-prompt flight graph journal](h06b-per-prompt-flight-graph-journal.md).
The [Gate H owner](../../../roadmap/rrflow-1.0/gate-h.md) retains H-06
acceptance; this package does not complete it.
